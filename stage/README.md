# QuotePilot 本机演示

从项目根目录运行 `python portable.py`，或在已预装依赖的 Windows x64 演示包中双击 Start_QuotePilot.cmd。每次启动会在系统临时目录建立一份 SQLite，创建两个不同的本机角色访问码，并打开与本次进程配对的浏览器窗口。仅回环 IPv4 接受连接。浏览器未出现时，请复制终端打印的完整网址。

浏览器执行真实 QuotePilot 接口。样例为 3 EA、PN-0001。依次复核需求、校对三家 PDF、核算不同策略、提交业务复核，由管理员确认风险、获批后下载 PDF 和 Excel。演示者在同一设备轮流扮演两种账户。供应商合成原件报价日按启动当日、有效期 60 天生成，单价和交期沿用样例。默认毛利率 20%、加工费 ¥1/EA、其他成本 ¥2，最低成本方案应为 ¥43.74。

宽行距供应商 PDF 的字段读取与登录身份写入复核轨迹均在该版本修复。使用系统临时演练库。正式部署沿用原服务入口，只有单独运行 portable.py 才启用本机向导。

从源码复现时，在 Python 3.12 环境运行 `python -m pip install -r stage/requirements.txt`。执行 `python stage/smoke_test.py` 可复核访问边界与样例导入。Windows 离线成品已含运行环境。这条路径没有外部模型调用；可在完整工作台查看本次演练产生的来源、审批和审计记录。
