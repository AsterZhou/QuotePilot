# QuotePilot 视觉与用语规范 / v0.4

## 核心方向：报价室，不是 AI 助手聊天框

设计隐喻是航空物料工作台 / 单据台：结构严谨、有边界、易追溯。主视觉使用带一点印刷质感的编辑排版，而不是常见的霓虹蓝紫、悬浮玻璃圆角、动画光球。

### 色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 深松绿 / Ink | `#152A2E` | 侧边栏与重大操作背景，稳定、精密 |
| 工作台纸白 / Paper | `#F8F6F1` | 页面基底，降低表格阅读负担 |
| 单据白 / Canvas | `#FFFDF9` | 业务信息卡 |
| 陶土橘 / Action | `#BD5238` | 核心 CTA / 溯源动作，与模板 AI 蓝紫拉开距离 |
| 暖金 / Highlight | `#D8AA62` | 编号与少量图例 |
| 绿灰 / Muted | `#72817E` | 信息层级中的辅助解释 |

### 字体

- 中文主文案使用系统原生无衬线字体（PingFang SC / Microsoft YaHei）。
- 关键论断、业务大标题使用宋体/Georgia 的衬线感。
- 件号、编号、金额与来源标识使用等宽字体。
- 数字不是装饰：每一个 KPI 都须来自可查数据库。

### 禁用文案

- “智能赋能、AI 驱动、革命性体验、一键智能化、数据洞察中心、全链路魔法”等没有实质业务含义的表述。
- “100% 准确”“实时自动报价”“已接入企业数据”等目前无法证明的断言。

### 推荐文案

- 页面主标题：「每份报价，都要有据可查。」
- 业务决策：「核价之前，先核证据。」
- 文件处理：「来件有迹可循。」
- 审核边界：「查得到，说明白；查不到，就保留待核价。」
- 数据分析：「让数据回答问题。」
- 明确状态：「可报价（待人工审批）」「待核价」「来源位置」「供应商报价有效期」「未提供」。

### 交互优先级

1. 溯源在行旁边，避免评委找不到“依据”。
2. 校验与拦截需要明确原因，不只给红/绿灯。
3. 负面结果也能成为演示亮点：缺价的记录不被默默删除。
4. 图表必须和下方 SQL 明细使用同一结果集。
5. 手机可操作；长表格横向滚动，但页面不整体溢出。
