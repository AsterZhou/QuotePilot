# QuotePilot 三分钟演示 · 2026-11-08

目标客户：工业零部件经销商、报价团队与采购专员。演示聚焦同一RFQ从来件到正式报价；所有客户、供应商、价格和文件明确标注合成。

## 录制顺序

| 时间 | 画面与操作 | 旁白要点 |
|---|---|---|
| 0–15秒 | 一封合成RFQ与附带原始需求 | 客户改数量、文件难核对、报价成本散落，报价团队需要一条可复核的处理链。 |
| 15–45秒 | 导入EML；证据复核页打开型号、数量、原文及文件定位；确认字段 | 每个重要字段保留来源。扫描件或不确定字段交人工，模型可信等级不冒充准确率。 |
| 45–75秒 | 同客户V2数量100→500，版本页对比，原报价需重新核算 | 稳定业务标识优先匹配，歧义交人工。旧审批快照不会被新需求覆盖。 |
| 75–115秒 | 三家合成供应商原件→结构化复核；成本、最快、平衡方案 | 同型号、规格、单位和件状才比较。采购、加工、运费、税费和其他成本逐项列出。20%毛利率使用成本÷0.8，公开评分规则。 |
| 115–145秒 | 业务账户审核→管理员审批；显示越权拒绝与风险确认 | AI或规则只建议，成本缺失禁止审批，两账户不能自审自批。演示账户是共享角色，未宣称个人SSO。 |
| 145–165秒 | 下载PDF/Excel，金额与快照一致；打开审计链 | 审批版本、来源摘要和文件生成记录可追溯。不会自动向客户发报价。 |
| 165–180秒 | 运行指标及能力状态 | 指标从保存记录计算，未知Token/费用留未知。现阶段是可测试的报价闭环，原生平台与公网能力按实证单列。 |

## 可重复验证

```bash
python scripts/business_cycle.py --output tmp/business_cycle.json
python -m pytest -q
```

脚本在临时目录创建独立SQLite，禁用赛事样例自动播种，仅导入自己生成的合成RFQ和供应商原件；使用ASGI TestClient，非公网HTTP。临时密码仅用于此进程，运行后恢复环境和应用DB路径。输出真实状态、毫秒耗时、真实生成ID及文件SHA，绝不伪造平台执行ID。

已提交的执行记录：`evidence/business_cycle.json`。脚本覆盖36次接口检查、2个版本、3个方案、独立审核审批、导出金额读回、只读SQL和备份恢复。SQL由脚本编写，不能宣传成本次真实AI自然语言调用。

## AI与平台展示边界

- 现有Genesis自然语言SQL、字段补充提取及MOI镜像代码保留；本轮新增闭环无需外部调用。录制时只有拿到真实成功回执才演示并注明时间。
- 未配置/不可用时展示清楚的不可用状态或原四个确定性快捷查询；不能剪辑成真实模型成功。
- MOI原生搜索历史报错provider_unavailable；本轮未重试。MatrixOne Snapshot/Branch/Diff/Pick/Merge未完成原生验收，不能将SQLite版本表称为这些API。
- 公开网页参考价格不是正式报价或实时库存；不展示虚构联网结果。
- 这是演示脚本，不是已录制视频；实际浏览器、录屏和公网验收仍待执行。
